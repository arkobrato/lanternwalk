# Lanternwalk

A calm five-minute adventure game with no way to lose. Carry a lantern from morning to nightfall, gather the small lights along the path, and stop for the three people who are glad to see you.

## Play

Download `index.html` and open it in any browser. The whole game is in that one file.

- Walk: arrow keys or A / D. On a phone, hold the on-screen arrows.
- Talk: the button that appears near each person, or Enter.
- Sound can be switched off in the top corner.
